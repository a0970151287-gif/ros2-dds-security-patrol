## 一、我的預測只對了一半，如實記錄

2026-09-01 事前寫下：「打已修補缺陷的六支（N2、N5、N4、N20、N24b、N8）
多半不會通過。」

| 預測 | 實際 |
|---|---|
| N2、N5、N20 不會通過 | ✅ **對** |
| N4、N24b、N8 不會通過 | ❌ **錯，三支都通過了** |

**預測錯在哪：我假設「漏洞修好 ⇒ 沒有訊號」。** 實際上通過的那些訊號
**全部是防禦的反應**，不是漏洞得逞：

```
cross_channel_relay : hmac_result.reason=channel_mismatch      ← HMAC 頻道綁定擋下它
health_spoof        : hmac_result.reason=malformed_envelope    ← 信封檢查擋下它
mission_spoof       : hmac_result.reason=malformed_envelope    ← 同上
scan_drift          : log_reject + guard_lock                  ← 守衛鎖定
```

**漏洞確實修好了，而且正因為修好了才產生可辨識的訊號。** 「已修補」與
「可識別」不是互斥的——這是我原本的推理裡缺的一環。

## 二、更重要的發現：gate 本身有缺口

五支通過個別判定，但兩兩比對：

```
mission_spoof 的訊號 ⊂ confused_deputy 的 ⊂ health_spoof 的
三者共用 hmac_result.reason=malformed_envelope
```

它們**對 normal 排他，卻對彼此不排他**。

**那正是這道 gate 本來要防的失效。** C2C-013 記錄的
`parameter_tamper` 與 `replay` 認不出來，就是因為觸發同一組五個通用特徵。
我的判準只寫了「候選 vs normal」，漏掉「候選 vs 其他候選」——
如果照個別判定的結果排 campaign，會一次放進三個互相混淆的類別，
然後看到 balanced accuracy 下降並以為是「類別太多」。

已修：`check_evidence_exclusivity.py` 加 `--pairwise`，判準變兩層：

```
對 normal 排他  → 這個類別「看得見」
兩兩互斥        → 這些類別「分得開」
```

## 三、三輪才跑成，每一輪的失敗都值得記

| 輪次 | 現象 | 根因 |
|---|---|---|
| 1 | 九支全部作廢，**零遙測事件** | telemetry 的 Unix socket 建在 `/mnt/c`（9p/drvfs），不支援——`Errno 95` |
| 2 | 九支全部 `rc=1` | 攻擊行程沒有 ROS 環境，`ModuleNotFoundError: rclpy` |
| 3 | ✅ 全部執行成功 | 攻擊時間改成比視窗短 5 秒，讓它自己結束 |

第三輪的根因值得單獨講：攻擊持續時間**等於**視窗長度時，orchestrator 會在
邊界送 SIGTERM，rclpy 的 signal handler 先呼叫 `rcl_shutdown()`，腳本的
`finally` 再關一次就拋 `rcl_shutdown already called` → 退出碼 1 →
`_attack_process_succeeded` 判定「攻擊沒有執行」。

**一個成功跑滿 30 秒的攻擊，因為關閉方式而被記成沒有執行。**

## 四、第一輪還印出過一個假的「通過 9 / 9」

smoke 腳本原本寫成

```bash
if python3 gate.py ... | tail -12; then PASSED=$((PASSED+1)); fi
```

管線的退出碼取自**最後一個指令**（`tail`），而 tail 永遠成功。於是不論 gate
判什麼，計數都加一——第一輪實際印出「**通過 9 / 9**」，而真實情況是
**九支全部作廢、零遙測事件**。

**一個回報「全部通過」而實際全部失敗的腳本，比沒有腳本更危險。** 已改成用
暫存檔接住輸出、再看 gate 自己的退出碼。

## 五、`discovery_recon` 被拒絕，而那是預期內的

N32 是被動偵察——**它的定義就是不產生應用層訊號**。gate 拒絕它是正確的：
在遙測事件層，一個只聽不說的攻擊者確實沒有專屬訊號。

它唯一的痕跡是 **participant 的存在本身**，那在身份層而不是遙測層。所以
`discovery_recon` 要用**身份通道**（2026-08-31 補起來的那條）判，不是這道 gate。
這反過來說明了那條通道的價值——**它是唯一能看見這種攻擊者的東西**。
