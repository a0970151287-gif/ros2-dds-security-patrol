# reaper 的第一個 live 證據，而步調持平不可歸功於它（2026-10-09）

`reap_attack_orphans.py` 在 13:25Z 上線時，它的八個單元測試驗的是**判準**
（期限在未來不碰、過期才收、寬限有地板、迴圈吞例外），不是 live 有效性。
本篇記下 `--loop` 路徑第一次真的收到東西，以及一個必須先說清楚的歸因限制。

---

## 一、事前判準，四項全過

判準寫在等之前（`wait_reap.sh` 的檔頭）：

```
① mega_reaper.log 應出現「收掉 N 個攻擊孤兒」，N 在 1–10 之間
② talker 應歸零
③ 若 400 秒後日誌仍只有啟動行而那些 pid 還在 ⇒ reap() 有問題
④ 若日誌沒長而 pid 消失了 ⇒ 那是批次邊界收的，不是 reaper
```

結果：

```
開窗 15:19:18Z   日誌  73 bytes   talker 7   pids 44351…44485
關窗 15:25:55Z   日誌 167 bytes   talker 0

2026-10-09T15:19:26Z 收掉 7 個攻擊孤兒（最久超過期限 4.7 分，domain ['30']）
7 個 pid 逐一確認：全部已收
```

⭐ 開窗 8 秒後 reaper 就醒來並收掉 ⇒ 它正好在那一刻結束 300 秒的睡眠。
「最久超過期限 4.7 分」= 寬限 2 分 ＋ 輪詢間隔，落在設計值內。
`domain ['30']` 與執行中的 campaign 相符（C2C-102 從 `/proc/<pid>/environ` 讀出）。

### 先排除三個會讓「沒有紀錄」被誤讀的解釋

| 懷疑 | 量到的 |
|---|---|
| 輸出被緩衝 | ❌ 每個 `print` 都有 `flush=True`；日誌 mtime 停在啟動那一刻 |
| 行程卡住 | ❌ `state S (sleeping)`、`wchan hrtimer_nanosleep` ⇒ 在 `time.sleep(300)` 裡 |
| 判準壞了 | ❌ `find_orphans(120)` **自己**回報那 7 個，`overdue 163s > 120s` |

真正的原因是 `reap()` 的 `if not orphans: return 0` —— **沒孤兒就完全不印**。
所以啟動後 23 輪（7,119 秒 ÷ 300）的空日誌是正確行為，不是失效。

## 三、重訓第 0 階段的記憶體上界（C2C-108 留下的推論收緊了）

C2C-108 的結論是「`features.py` 一個位元不改」，而它留了一句
「**9 GB 上限下跑得完仍然是推論不是觀測**」。用已校準的比率從檔案大小推：

```
校準（C2C-108）：31.4 MB 壓縮 → 3,737,684 封包 → 峰值 1.151 GB  ⇒ 36.7× 壓縮後大小
```

| 資料集 | 紀錄數 | 中位 | p99 | max |
|---|---:|---:|---:|---:|
| `dataset_mega` | 2,903 | 2.9 MB | 19.2 MB | **31.4 MB** |
| `dataset_rerun300` | 305 | 0.0 | 0.1 | 0.1 |
| `dataset_live` | 1,100 | 0.1 | 0.1 | 0.1 |
| `refresh` | 910 | 0.0 | 0.1 | 0.2 |
| **合計** | **5,218** | 0.1 MB | 17.4 MB | **31.4 MB（11.39 GB）** |

```
最大場次推估峰值 1.15 GB      可用預算約 7.3 GB（9 GB 上限 − WSL 約 1.7）
⇒ 餘裕 6.15 GB
```

⭐ 而有一個**不隨時間惡化**的性質：資料集從 2,053 場長到 2,903 場，
而最大的那一場**沒有變**（仍是 `20260920T064608…_unauthorized_participant_7afa648f`）
⇒ 新場次都比它小 ⇒ **9 GB 的餘裕不會被後續資料吃掉**。

⚠️ 三個限制：
- 這是**從檔案大小推的上界，不是觀測**。`features.py` 自那次卡機後沒有再跑過。
- 最大那一場正是 C2C-108 的校準場次 ⇒ 推估與實測一致是**定義**不是獨立驗證。
- **page cache 會另外吃掉 11.39 GB 的讀取量** —— 那正是 C2C-108 判定的主因，
  由 `autoMemoryReclaim=gradual` 處理，而那一半也沒有被觀測過。
