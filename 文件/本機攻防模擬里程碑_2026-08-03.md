# SROS2 智慧防火牆：本機攻防模擬里程碑

日期：2026-08-03  
範圍：本機離線／smoke 演練；不發送攻擊封包、不修改主機防火牆、
不宣稱跨主機或實體防火牆驗收。

## 一、本輪完成內容

### 1. Live telemetry 原始事件格式

新增 `firewall_lab/live_telemetry_collector.py`：

- 每筆事件固定包含 session、sequence、時間、來源、事件類型及 bounded details。
- 只接受 allowlisted event type，不接受任意 command、feature 名稱或 secret 欄位。
- count、ratio 分子／分母、heartbeat gap 皆有限制；不合法資料 fail closed。
- 使用單一 writer、逐筆 fsync，sequence 缺號、時間倒退或 session 不一致會被拒絕。

### 2. 14＋18 維同窗融合管線

`firewall_lab/features.py` 已新增：

- 18 維 ROS／SROS2 telemetry 聚合；
- 以 `session_id + 8 秒 window` 對齊 network 與 telemetry；
- 產生 `telemetry_features.csv`；
- 產生 live `fusion_features.csv`；
- `--require-multimodal` fail-closed 品質閘門；
- 缺 telemetry、缺 collector tick、視窗不完整、metadata 不一致、NaN／Infinity
  或 ratio 超界時拒絕。

目前 contract 仍維持 `blocked`，因為 ROS／SROS2 runtime producers 尚未接到
collector，也尚未以真實 loopback session 證明全視窗 coverage。測試 fixture
不得冒充 live telemetry。

### 3. 本機離線攻防演練器

新增 `firewall_lab/local_simulation.py`：

- 只讀取 held-out synthetic rows；
- 模型必須先通過 HMAC 驗章；
- 只輸出 constrained action intent；
- IP 封鎖只記錄「模擬 300 秒 TTL」，不執行 OS command；
- 報告固定標記
  `offline_synthetic_local_simulation_not_live_or_cross_host_evidence`。

結果說明：只看 14 維 network features 的分類能力仍不足；這不是失敗隱藏，
而是支持下一階段加入 18 維 telemetry 並做 network-only／telemetry-only／fusion
消融實驗的直接證據。

## 四、下一個里程碑

1. 將 monitor、HMAC、ROS graph、D1–D6 與 QoS 的 metric producers 接到
   collector；事件不得包含 HMAC secret、私鑰或完整敏感 payload。

3. 再跑一個低風險、短時間、無憑證 participant session，確認 SROS2 deny 與

## 五、跨主機前的現況限制

- 現有 Kali VM 仍是 NAT，不是隔離攻擊機。
- 目前可用 RAM 約 3.8–4.8 GiB，不適合立即雙開 Kali＋Ubuntu/Jazzy。
- Windows 有一條過寬的 `ROS2 DDS UDP wide` 入站規則；未經明確授權，本輪
  不修改設定，但跨主機前必須收斂。
- WSL mirrored 網路不是跨主機證據；同機結果只能寫
  `local_adversary_only_not_cross_host`。
