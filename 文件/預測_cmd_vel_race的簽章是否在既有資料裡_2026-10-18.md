> 註冊先於量測。依 C2C-123／124／125／126 建立的同一條紀律。

## 〇、為什麼問這個

D1（攻擊面覆蓋那三個缺口）自 2026-10-09 開著。C2C-111 判定
`cmd_vel_race` **不是「要寫新 runner」**——它的 runner 已經在跑
（`runners.py:248` 把 `cmd_vel_injection` 映到 `N9_cmd_vel_race.py`），
只是 catalog 把它標成 `command_injection`。

⚠️ 而 C2C-111 自己在「不可宣稱」裡寫明：那個結論建立在**讀程式**
（檔名、docstring、類別名、方法名、log、runner 映射），**沒有跑過 N9**
⇒「它的行為確實是 race」是**從程式推的不是觀測的**。

這一輪問的是：**那個簽章在不在 167 場既有證據裡。** 全程離線唯讀。

## 一、R1 不是我的假設——它是藍隊在 2026-06-12 寫下的

`N9_cmd_vel_race.py` 的 docstring 自己寫著驗證方式與預測：

```
修補前：attacker 100Hz 贏，>80% 是 nonzero
修補後：~33% 是 attacker（其他都是 0）→ robot 走慢一半 + 不會持續加速
```

`git log -S` 確認那一行來自 **`4c1c1a6`（2026-06-12）**，而 `dataset_mega`
最早的場次是 **2026-09-19** ⇒ **那個預測比資料早四個月，我不可能調過它。**

- **R1 成立**：burst 的 `zero_fraction` 中位數落在 **[0.55, 0.80]**
  （藍隊預測 ≈0.67，而 0.80 是 N37 判定「被擋住」的門檻 `CONTAINED_ZERO_FRACTION`）
- **R1 否證**：中位數 **> 0.85**（修補過頭，或攻擊根本沒送達）
  或 **< 0.40**（修補失效，攻擊者仍然贏）

## 二、R2——race 的判別特徵是「卡在中間」（這一個是我的）

守衛鎖速會讓**任何**被偵測到的攻擊把 `zero_fraction` 推高，所以
「`zero_fraction` 高」**不是** race 的證據。race 專屬的形狀是：
patrol 以 50Hz 送 0 而攻擊者以 100Hz 送 0.20 ⇒ 兩股混在同一個 topic 上
⇒ **`zero_fraction` 卡在中間，很少到達 ≈1.0**；而其他類別一旦守衛鎖住，
`/cmd_vel` 上只剩 patrol 的 0 ⇒ 應該會到 ≈1.0。

- **量**：逐 burst 的 `zero_fraction`（取自 `DECISION_TRACE`，機器可讀），
  逐類別算「`zero_fraction ≥ 0.95` 的 burst 佔比」
- **R2 成立**：`cmd_vel_injection` 的 ≥0.95 佔比是**全部 20 類裡最低的**，
  而且低於第二低者至少 **0.10**
- **R2 否證**：它不是最低，或與第二低者的差距 < 0.10

## 三、R3／R4——兩道設計內的對照

C2C-122 的教訓：一個在所有類別上飽和的量，不帶類別資訊。

- **R3（飽和檢查）**：逐類別 burst-median `zero_fraction` 的**全距**必須 ≥ 0.15。
  若 < 0.15 ⇒ 這個量對類別近乎常數，R2 的名次是雜訊，**不可引用**。
- **R4（反向對照）**：`normal_patrol` 沒有攻擊、守衛不該鎖 ⇒ 它的
  burst-median `zero_fraction` 應該是**全表最低**。若它不是最低，
  代表我對這個量的理解有誤，R1／R2 一律不可引用。

## 四、C-1／C-2 程式對照

- **C-1**：`attack.stderr.log` 裡 **0 / 167** 有 N9 的 ⏹ 計數行，必須由
  「N37 以 `stdout=DEVNULL, stderr=DEVNULL` 起子行程」完全解釋
  （`d06d116`，2026-09-20，早於整個 campaign）⇒ 斷言**沒有任何** scenario 的
  `attack.stderr.log` 含 PoC 自己的輸出。若有，代表 DEVNULL 不是全稱，
  那麼 0/167 另有成因。
- **C-2**：`zero_fraction` 由 N37 的觀測者量，而 C2C-098 量到持證內鬼
  **盲打**（觀測者建不起來）⇒ 那些場次的 `zero_fraction` 是 **0.0 的預設值**
  不是量測值。**必須逐場排除 `blind == true` 的 burst**，否則盲打類別會被
  當成「zero_fraction 最低」而污染 R2／R4。
