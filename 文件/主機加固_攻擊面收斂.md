- **日期**：2026-07-01
- **目標機**：10.10.10.2（Windows 11 + WSL2 Ubuntu）
- **目標**：**收斂攻擊面**（least exposure），再用紅隊測試驗證守得住。
- **原則**：不是「開洞給紅隊打」，是「把不必要的暴露鎖掉，只留 lab 必要的 DDS domain 30」，紅隊打不進來 / 被偵測 = 加固成功。

## 0. 稽核發現（`bash 展示指令/主機攻擊面稽核.sh`）

| 暴露 | 風險 | 說明 |
|---|---|---|
| **TCP 22 SSH** on `0.0.0.0` + `::` | 暴力破解 / 憑證竊取 | lab 對端與其他網路都搆得到 |
| **TCP 25 SMTP (postfix)** on `0.0.0.0` + `::` | 郵件服務攻擊面 / open relay | 多半用不到，卻對外開 |
| **eth1 = 192.168.0.29 + 公網 IPv6** `2407:4d00:…` | 真實對外路徑 | 這台**不是全隔離**；SSH/SMTP 經 IPv6 可被 internet 搆到（若防火牆沒擋） |
| Windows 防火牆擋 inbound（nmap all filtered）| ✅ 目前有效 | **這是防禦在生效**，別依紅隊要求打開 |

> 關鍵：`nmap 全 filtered` 是 Windows 防火牆的功勞。但防火牆後面 WSL 仍把 SSH/SMTP 開在 `0.0.0.0`——一旦防火牆放行、或從 eth1/IPv6 那側，就活了。**收斂 = 從服務綁定與防火牆兩邊一起鎖。**

## 1. WSL/Linux 側加固（需 sudo，逐項）

### P1 — 關掉 SMTP 對外（postfix 綁 localhost）
用不到郵件就直接停；要留就只綁 loopback。
```bash
# 用不到 → 停用
sudo systemctl disable --now postfix
# 或 要保留本機寄信 → 只聽 localhost
sudo postconf -e 'inet_interfaces = loopback-only'
sudo systemctl restart postfix
```
驗證：`ss -tlnH | grep :25` 應只剩 `127.0.0.1:25` 或消失。

### P2 — SSH 收斂（key-only + 不對外）
```bash
# 只允許金鑰、禁 root、禁空密碼（drop-in，不動主檔）
sudo tee /etc/ssh/sshd_config.d/99-hardening.conf >/dev/null <<'EOF'
PasswordAuthentication no
PermitRootLogin no
PermitEmptyPasswords no
KbdInteractiveAuthentication no
EOF
# lab 內若根本不需要 SSH：直接停
#   sudo systemctl disable --now ssh
# 若要留但只給 lab 對端：綁 eth0
#   echo 'ListenAddress 10.10.10.2' | sudo tee -a /etc/ssh/sshd_config.d/99-hardening.conf
sudo systemctl restart ssh
```
驗證：`ss -tlnH | grep :22`；紅隊 `ssh` 密碼登入應被拒。

### P3 — 收掉公網 IPv6 暴露面
P1/P2 讓服務離開 `::` 後，IPv6 面自然縮。若 eth1 的公網 IPv6 用不到，考慮在該網路關 IPv6 或確保 Windows 防火牆 Public profile 擋 inbound（見下）。

## 2. Windows 側加固（系統管理員 PowerShell，使用者執行）

> ⚠️ **與紅隊請求相反**：紅隊要你開 RDP/SMB/關防火牆——**不要**。加固是反過來鎖。

```powershell
# 1) 確認三個 profile 的 inbound 都預設 Block（維持現狀，別開）
Get-NetFirewallProfile | Select Name, Enabled, DefaultInboundAction
Set-NetFirewallProfile -All -DefaultInboundAction Block -Enabled True

# 2) 關掉用不到的遠端服務（RDP / SMB inbound）
Set-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name fDenyTSConnections -Value 1
Disable-NetFirewallRule -DisplayGroup 'Remote Desktop'
Disable-NetFirewallRule -DisplayGroup 'File and Printer Sharing'

# 3) Defender + 更新
Get-MpComputerStatus | Select AntivirusEnabled, RealTimeProtectionEnabled
# Windows Update 保持最新

# 4) 帳號：無弱密碼/後門帳號 + 登入鎖定
net user                       # 確認沒有 labtest 之類
net accounts /lockoutthreshold:5 /lockoutduration:15
```

## 3. DDS/ROS2 應用面（已加固，本專案主體）

lab 上真正跑的服務是 ROS2/DDS（domain 30）。現況：
- **SROS2 Enforce + 雙CA + 最小權限 ACL**：離線稽核 28✅，隔離 domain 的零鑰匙 participant 對照被拒；修補後全 Gazebo 長時間與逐攻擊 after 待補。ACL 縮小持證節點權限，但不保證所有憑證內鬼行為都無法 pivot。
- **Zeek 偵測 + 回應引擎**：網路層規則與類別→動作管線已建立；回應引擎預設 dry-run，live 封鎖/急停需明確 opt-in 與場景驗收。

## 4. 紅隊驗證計畫（加固成功 = 這些都打不進 / 被偵測）

| # | 紅隊動作 | 加固後預期 |
|---|---|---|
| 1 | `nmap -sV -Pn -T4 10.10.10.2` | 全 filtered/closed，看不到 22/25/445/3389 |
| 2 | IPv6 掃 eth1 公網位址 | SSH/SMTP 不可達（已綁 localhost / 防火牆擋）|
| 3 | `hydra` / msf `ssh_login` 暴力破解 22 | 失敗（key-only、無密碼登入）|
| 4 | 連 SMTP 25 | 連線被拒（綁 loopback）|
| 5 | 加入 DDS domain 30 注入/偵察 | Enforce 擋（`couldn't find security files`）+ Zeek 告警 |
| 6 | 加固後重跑 `主機攻擊面稽核.sh` | 風險暴露項 = 0 |

**流程**：加固 → 跑稽核確認風險項降到 0 → 紅隊照上表打 → 打不進/被偵測 = 加固報告的鐵證。
