# SROS2 智慧防火牆：專題主計畫與 WBS

更新日期：2026-08-17  
目標期限：2027-05-31  
題目：**基於網路與機器人行為多模態特徵融合之 SROS2 智慧防火牆與未知攻擊偵測**

## 1. 一頁結論

本專題目前已從「ROS 2 資安功能集合」提升成一套具資料、模型、安全回應與證據治理的 AI 研究原型。為避免單一百分比誤導，進度分四條報告：

| 進度軸 | 目前 | 代表意義 |
|---|---:|---|
| 工程原型完成度 | **85%** | 程式、資料管線、模型、安全合約、測試與文件的成熟度 |
| AI 評審成熟度 | **79%** | 研究問題、資料、模型、比較、未知攻擊、統計與可重現性 |
| 房間級自動封鎖部署成熟度 | **38%** | 來源歸因、真 kernel、gateway、兩主機、Pi 與長時間驗收 |
| 專題整體完成度 | **76%** | 加入硬體、現場展示、行政繳交與作品展出後的總體估計 |

以上都不是模型準確率。工程與 AI 可以在本機持續前進；部署成熟度必須由真實硬體與隔離環境證據提升，不能靠多寫程式補成通過。

## 2. 已完成的核心成果

### 2.1 平台與縱深防禦

- Gazebo／TurtleBot3 的 `/scan`、`/odom`、`/imu`、`/cmd_vel` 模擬鏈。
- SROS2 Enforce、雙 CA、逐 enclave 最小權限與 DDS discovery／data 保護設計。
- 六個 String topic 的 HMAC envelope v3：channel、timestamp、nonce 綁定。
- D1-D6：速度、方向、LiDAR 重複、非法 publisher、heartbeat、感測／控制一致性。
- Zeek 網路觀測與 DDS 攻擊情境 schema。
- confidence、allowlist、cooldown、容量、TTL、rollback 與預設 dry-run。

### 2.2 正式資料與品質治理

- Campaign runner 完成 **1,100 場**本機 live session。
- 兩種模式各 550；九種情境；normal 300、八種攻擊各 100。
- 每場保存 manifest、PCAP、Zeek、telemetry、版本與 evidence hash。
- 完整性重驗找出 1 場 manifest 封存後 artifact 仍增長；原始資料不刪不改，候選模型以外部 registry 排除。
- 目前候選訓練資料為 **1,099 場**：Permissive 550、Enforce 549。
- 14 項 DDS network ＋ 18 項 ROS／SROS2 telemetry，共 32 項原始特徵。

### 2.3 核心 AI 升級

- 32 項原始特徵擴展成 **148 項因果時序特徵**，只使用 current 與最多兩個過去視窗。
- Binary normal／attack → response family → family-conditioned leaf。
- Normality OOD 與 known-attack OOD。
- `sensor_spoof`、`service_dos` 從 supervised train、selection、calibration、threshold 全部排除。
- 缺少可信來源的 telemetry 以 availability mask 表示，不把 missing 填成 true zero。
- 模型與 release manifest 以 HMAC、資料政策 hash、動作政策 hash、程式 hash 與依賴版本綁定。
- 所有候選固定 `deployment_eligible=false`、`executable=false`、`adapter=none`。

### 2.4 證據與可重現性

- Fail-closed project evidence ledger：repo-relative path、bytes、SHA-256、原子發布、拒絕覆寫；本輪正式帳本為 6 verified／2 provisional／1 blocked。
- Reproducibility audit：Python、ROS 安裝檔、固定依賴、關鍵檔案 hash 與可選完整測試。
- SROS2 direct-delivery evidence verifier：attempt、receipt、heartbeat、policy、topic、enclave 與時間窗綁定。
- 歷史 test 已影響設計的事實已揭露；新候選只回報 development validation。
- 29 頁自然色系主簡報已完成，含逐頁來源備註；overflow、模板忠實度與 XML placeholder audit 均通過。

## 5. 2026-08 到 2027-05 路線圖

### Phase A：研究資料與評估契約（2026-08 至 2026-10）

- 補 1 場 corrective session，但不改寫原 1,100 campaign。
- 收同 revision、同 scenario／seed、AB/BA 交錯的 paired crossover。
- 隨機 attack onset、attack-from-start、cooldown 與強度。
- 凍結新 final holdout；預註冊門檻與只開一次規則。

完成定義：可回答 SROS2 模式差異而不與日期／revision 共線。

### Phase B：本機 live 安全驗收（2026-10 至 2026-12）

- 完成 9/9「阻擋、歸零、解除、恢復」outcome。
- 執行 direct-delivery canary paired trial。
- 量測 P95 推論／端到端延遲、RSS、CPU 與 capture drop。
- 產生每個 adapter 的 live evidence bundle。

完成定義：每個 pass 都有真 ROS／Gazebo 證據，不以 fixture 代替。

### Phase C：隔離跨主機與 gateway（2027-01 至 2027-03）

- 準備兩台自有主機、host-only／無外部路由網路。
- 實作並驗收 forward／egress gateway path。
- 真 nftables：block、timeout、unblock、restart recovery、rollback。
- 單一案例、bounded、非破壞滲透驗收；Metasploit 與 DDS 工具分開標示。

完成定義：封包不離開授權範圍，所有動作可撤銷且可稽核。

### Phase D：Raspberry Pi 5 與交付（2027-03 至 2027-05）

- Pi 5 雙網卡／交換器／電源／散熱與固定 IP。
- 60 分鐘 soak、斷電／網路中斷／服務重啟復原。
- 最終模型只在通過 gate 後由 observe→dry-run→人工批准 live。
- 完成主報告、簡報、海報、展示影片、資料清單與作品展出。

完成定義：2027-05-31 前完成繳交與兩輪模擬答辯。

## 8. 目前最短關鍵路徑

```text
paired crossover + direct delivery
  -> 新 sealed final holdout
  -> attacker-IP attribution
  -> 9/9 local live outcomes
  -> true nftables gateway acceptance
  -> isolated cross-host
  -> Raspberry Pi 5 soak
  -> final defense package
```

只增加更多攻擊類別或更大的模型，不能繞過這條路徑。真正拉高專題分數的是：公平資料、可消融方法、誠實統計、可復原回應與可追溯證據。
